# FlowOps web application

The implemented React application uses JavaScript and JSX with Vite, React Router, TanStack Query, and Lucide icons.

Screens include sign in, workspace overview, requests, request editing and details, approval inbox, policy settings, membership directory, audit history, and an in-application guide.

Run `npm run dev` from the repository root to start the complete local stack, or `npm run dev:web` for the frontend only when the API is already running. The frontend proxies API and session routes to port 8011.

See [local development](../../docs/LOCAL_DEVELOPMENT.md) and [implementation](../../docs/IMPLEMENTATION.md).
